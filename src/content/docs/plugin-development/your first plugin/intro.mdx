In this section we'll learn to write our first Plugin in Lorealm using the Rust
Programming Language!

**In this guide we'll cover:**
1. How to install Rust and all the recommended tools
2. Creating a new project using `lorealm-plugin-cli`
3. Installing the Plugin in Lorealm as a development Plugin
4. Writing a Plugin that adds an inspector element with a button that counts every
time the user clicks it, and remembers the count across sessions

**What we won't cover:**
1. Programming concepts
2. How to release your Plugin to the Marketplace

Exciting stuff!
